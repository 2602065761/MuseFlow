# 创作方案书：《蚀》

> *让风沙成为雕塑的执笔人*

---

## 一、创作理念

### 核心命题

**人类只负责"开始"，自然决定"结局"。**

这不是一件被放置于沙漠中的作品，而是沙漠自己缓慢完成的作品。若干粗糙的生土块散落于鸣沙山沙丘坡面，初始形态毫无艺术感——像工地的边角料，像考古现场刚清理出的遗物，朴素、突兀、未完成。此后数年，风和沙接手：春夏季的东风打磨出流线型纹理，秋冬季的西北风磨圆所有棱角，跃移的沙粒在底部掏出凹陷。人造的几何体块逐渐蜕变为天然的风蚀雕塑，最终与周围的沙丘共享同一套物质、同一种形态语言，再也分不清哪是人造、哪是自然。

### 概念阐述

《蚀》追问的是**创作的主体性**：如果一件作品的最终形态完全不由艺术家控制，那么"艺术家"的身份应该归属谁？

当代艺术长期深陷"人类中心主义"——无论是观念艺术还是大地艺术，创作者始终是那个"说了算"的人。即使 Smithson 的 Spiral Jetty 被湖水淹没 31 年，人们仍称它为"Smithson 的作品"。但《蚀》试图走得更远：初始形态毫无"艺术意图"——它刻意回避所有视觉愉悦，让自己看起来像被遗弃的建筑废料。只有当风沙开始"雕刻"它时，作品才真正诞生。

这在某种意义上是一份**对自然力的委托创作合同**——艺术家只提供了"材料"和"位置"，风沙负责"形式"。作品的作者栏上，写的是风。

## 二、视觉方向

### 色彩方案

| 角色 | 色彩 | 理由 |
|------|------|------|
| **主色调** | 生土褐黄 `#C4A45A` | 来自敦煌本地土质，与鸣沙山五色沙同源 |
| **辅助色** | 风蚀灰 `#B8B0A0` | 风蚀后的表面氧化层 |
| **强调色** | 沙金黄 `#D4B870` | 鸣沙山的标志性金色 |
| **环境色** | 天空蓝 + 沙丘曲线 | 作品不是孤立的——天空和沙丘是它的"画框" |

### 材质与媒介

- **生土坯**（主体材料）：就地取敦煌附近黄土，不添加化学稳定剂（水泥/石灰）。不同配比方案：
  - A 块：纯生土 + 水 → 考察最脆弱材料的蚀变速度
  - B 块：生土 + 30% 鸣沙山沙 → 考察沙含量对风蚀的加速/减缓效应
  - C 块：生土 + 草秸纤维 → 考察有机纤维的抗风蚀能力
  - D 块：生土 + 5% 盐（模拟盐碱地） → 考察盐结晶对表面的作用

- **模具**：木制可拆卸模具（30×30×40cm），脱模后保留手工抹平的粗糙肌理

- **放置平台**：不做任何地基处理——土块直接放置于沙丘坡面，坡度约 15-25°（鸣沙山自然坡度），使风沙的跃移颗粒能自然流经表面

### 空间关系

```
      鸣沙山沙丘俯视图

        风向 →

      ┌──────────────────┐
      │                  │  沙丘脊线
      │   A块  C块       │
      │                  │
      │     B块    D块   │  ← 松散网格排列
      │                  │     间距 2-3 米
      │         E块      │
      │                  │
      └──────────────────┘

      坡面约 15-25° 倾角
      土块直接置于沙面——无基座、无固定
```

土块间距 2-3 米，不追求"构图"，排列逻辑类似田野调查的采样网格。每块旁边插一面小旗标注编号（类似科学实验)，强化"这不是艺术，这是实验"的初始误读。

## 三、技术方案

| 环节 | 方案 | 工具/设备 |
|------|------|----------|
| 取土 | 敦煌郊区取黄土（需确认可操作区域，避开景区保护范围） | 铁锹、编织袋 |
| 配比实验 | 四种配方样本（各 10×10cm 小样），先在敦煌当地做 1 个月自然风化测试，验证差异 | 电子秤、容器 |
| 制模 | 木板拼装 30×30×40cm 模具 5 个，内壁不涂脱模剂（保留粗糙表面） | 木板、钉子、锤子 |
| 成型 | 湿土填入模具，手工夯实，脱模后阴干 7 天 | 手工工具 |
| 运输与放置 | 将阴干后的土块运至鸣沙山选定坡面，按网格放置 | 小型货车/人工搬运 |
| 记录系统 | 每半年（春/秋）固定机位拍摄，记录风蚀进度 | 相机 + GPS 定位 + 三脚架 |
| 呈现方式 | 年度"风蚀年鉴"——对比照片 + 土块实物（如课程展允许带回部分） | 打印输出 + 装置 |

### 敦煌鸣沙山关键环境数据

| 参数 | 数值 | 对作品的影响 |
|------|------|-------------|
| 年降水量 | < 40mm | 雨水冲刷几乎可忽略——风是唯一的主要塑造力 |
| 年蒸发量 | 2488mm | 土块始终保持干燥，不会因水分软化坍塌 |
| 主导风向 | 春夏东风 / 秋冬西北风 | 季节性交替打磨不同面——产生方向性纹理 |
| 沙粒成分 | 五色细沙（红黄绿黑白） | 跃移颗粒粒径均匀，风蚀效果稳定可预期 |

## 四、制作时间线

| 阶段 | 时间 | 产出物 | 备注 |
|------|------|--------|------|
| **前期调研** | 第 1-3 天 | 材料实验报告 | 四种配比小样制作 |
| **场地确认** | 第 4-5 天 | 放置位置 GPS 坐标 | 需联系鸣沙山管理方确认合规性 |
| **取土与备料** | 第 6-8 天 | 黄土 200kg+ | 筛选、晒干、粉碎 |
| **模具制作** | 第 9-10 天 | 5 个木模 | |
| **土块成型** | 第 11-14 天 | 5 块生土坯 | 分层夯实，阴干 |
| **运输与放置** | 第 15-16 天 | 作品就位 | 人力搬至坡面，记录初始影像 |
| **首轮记录** | 放置后第 30 天 | 第一阶段对比照 | 观察初始风蚀迹象 |

> ⚠️ 核心区别：传统作品在"放置"步骤之后即宣告完成。《蚀》在放置步骤之后才刚刚开始。课程展呈现的是"进行中"的作品，而非"已完成"的作品。

## 五、参考案例

| 艺术家 | 作品 | 年份 | 借鉴点 |
|--------|------|------|--------|
| Danae Stratou (D.A.ST.) | *Desert Breath* | 1997 | "侵蚀不是意外，是作品意义的核心"——预设了消解为作品的一部分 |
| Robert Smithson | *Spiral Jetty* | 1970 | 熵美学理论化；将自然力视为"地质代理人" |
| Jim Denevan | *Angle of Repose* | 2022 | 沙的自然休止角决定形式；强调软化、阴影、变化 |
| George Geyer | *Surfline Erosion* | 1981 | "作品始于几何和谐，经熵走向随机混沌"——全过程记录 |
| Jonathon Keats | *The Erosion of Time* | 2024 | 将侵蚀速率作为环境变化的"日历" |

### 与本作品的核心差异

以上所有案例中，**初始形态都由艺术家高度设计过**（螺旋、锥体、同心圆）。《蚀》的区别在于：初始形态刻意回避美学设计——"未完成"不是姿态，而是方法论。艺术的诞生时间是风沙开始雕刻的那一刻，不是艺术家放下土块的那一刻。

## 六、展览呈现方案

### 物理展区

- **中央**：放置 1 块已完成 6 个月风蚀的土块实物（如条件允许从鸣沙山取回一块）
- **墙面**：大幅喷印"风蚀年鉴"——6 组对比照片（初始 vs 1 月 vs 2 月 vs 3 月 vs 4 月 vs 6 月）
- **展台**：四种配比材料的 10×10cm 小样 + 风蚀前后的表面显微照片
- **角落**：播放一段 3 分钟的延时短片（如有条件拍摄）

```
它的作者是一阵东风和一场沙暴。

```

## 七、答辩 Q&A 预演

**Q1: 如果风沙把土块完全摧毁了，这还是艺术吗？**

A: 这正是作品想探讨的核心问题。如果"摧毁"意味着回到沙丘的自然状态——那就说明自然完成了它的工作。Desert Breath 的创作者 Danae Stratou 说过：消解本身就是一种"对时间的测量"。从观念层面看，完整消解不是失败，而是作品最彻底的完成——它证明了人类那一点点干预在自然面前微不足道。

**Q2: 这个作品和"随便堆几块土"有什么区别？**

A: 区别在于"声明"。杜尚的小便池和百货商店的小便池在物质上没有区别，区别在于杜尚签了名、放进了美术馆。同样的土块放在工地就是废料，但当你声明"我邀请风沙来完成它"，并且配有完整的材料配比实验、定期摄影记录、理论框架，它在观念上就进入了艺术场域。关键在于创作意图的"框定"——艺术家框定了一个"让渡主权"的行为，这个行为本身就是艺术。

**Q3: 你如何记录"未完成"的作品？**

A: 通过"过程文件"而非"完成品"来呈现。具体包括：(1) 土块配比实验报告；(2) 每月固定机位对比照片（参考科学采样而非摄影艺术）；(3) 风蚀程度的量化记录（重量变化、表面粗糙度变化、棱角弧度变化）；(4) 一份"风蚀日志"——文字记录每次观察时土块的状态。这些过程文件合在一起，就是作品本身——因为《蚀》从来就不是土块，而是"土块在风中变化"这个事件。
