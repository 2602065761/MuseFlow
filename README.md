# 🎨 MuseFlow — 多 Agent 协作的艺术创作研究引擎

> 将 6 小时的创作前期调研压缩到 30 分钟，把碎片化灵感变成结构化创作方案书。

## 项目简介

MuseFlow 是一个基于 OpenClaw 和 Claude Agent SDK 构建的多 Agent 协作系统，专为艺术创作者设计。它通过 3 个专业化 Agent 的协作流水线，解决艺术创作中"空白画布恐惧症"——灵感碎片散落、调研深度不足、方案迭代无记录三大痛点。

## 架构概览

```
 用户输入主题
      │
      ▼
┌──────────────────────┐
│  ① 研究采集 Agent    │  并行搜索 + 视觉采集
│  (信息广度)          │  Exa 搜索 + 浏览器截图
└──────┬───────────────┘
       │ 结构化研究简报 (JSON)
       ▼
┌──────────────────────┐
│  ② 概念提炼 Agent    │  5 步长链推理 ★
│  (思维深度)          │  解构 → 定位 → 匹配 → 生成 → 自评
└──────┬───────────────┘
       │ 概念矩阵 + 创作方向
       ▼
┌──────────────────────┐
│  ③ 方案生成 Agent    │  产出交付
│  (最终交付)          │  Markdown 方案书 + HTML 参考板
└──────────────────────┘
```

## Agent 职责

| Agent | 类型 | 核心能力 |
|-------|------|---------|
| `research-agent` | 并行采集 | 主题拆解 → 多维度搜索 → 去重聚类 |
| `concept-agent` | 长链推理 | 5 步推理链：解构 → 风格定位 → 范式匹配 → 方向生成 → 可行性自评 |
| `synthesis-agent` | 结构化生成 | 方案书 + Mood Board + 答辩 Q&A + 参考板 HTML |

## 协作机制

- **任务队列编排**：通过结构化 JSON 在各 Agent 间传递上下文
- **异常回退**：概念 Agent 自评可用度 < 60 分时，自动触发补充搜索
- **并行优化**：研究采集 Agent 的 4-6 个搜索维度并行执行

## 运行环境

- **平台**：CherryStudio + OpenClaw

- **工具依赖**：Exa 搜索、浏览器自动化（MCP Browser）、文件系统
